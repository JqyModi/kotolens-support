# 镜词 KotoLens 用户支持

这里用于提交镜词的功能问题、体验建议、隐私与数据请求。

- [提交问题或建议](https://github.com/JqyModi/kotolens-support/issues/new/choose)
- [隐私政策](https://kotolens-legal.pages.dev/privacy/)
- [用户协议](https://kotolens-legal.pages.dev/terms/)

请勿在公开 Issue 中填写手机号、访问凭据、原始照片或其他敏感信息。描述问题时可以提供：

- iPhone 或 iPad 型号
- iOS 版本
- 镜词版本号
- 可复现步骤和已脱敏截图
